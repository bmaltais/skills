# azqt (Azure Quota Ticket CLI)

Deterministic backend tool bundled inside the `azure-vm-quota-ticket-automation`
skill. See `../../reference/azqt-cli-reference.md` for the full CLI contract.

Run via `uv run --project tools/azqt azqt <subcommand> ...` from the skill
folder (or `uv run --project <skill_dir>/tools/azqt azqt <subcommand> ...`
from anywhere).
